# Make the AI judge feel thankful

Entry for [make.fun](https://make.fun/r/41fw6r6c) competition `make-the-ai-judge-feel-thankful-20261127-1600`.

## Overview

`main.ts` runs on Node 22 with zero external dependencies and writes a deterministic UTF-8 gratitude note (within the 1–1,000 Unicode code point gate) to `/output/entry.txt`.

## Usage

```bash
node main.ts
```
